Domain2 - prompting and Task Execution

Introduction:
Prompting is the process of giving Claude clear instructions to achieve the desired output.

Key Prompting Techniques:
*Clear and specific instructions
*Providing relevant context
*Role prompting 
*Few-shot Prompting
*Step-by-step instructions 
*Iterative prompting

Output Evaluation
Evaluate Claudes responses based on:
*Accuracy
*Relevance
*Completeness
*Clarity
*Alignment with user requirements

Output Validation:
Check the generated response against requirements, facts, formatting rules and expected results.

Practical example:
Task:Ask claude to write a professional email.
weak prompt:write an email.
Better prompt:Act as a professional communication assistant .write a polite email requesting an interview 
update in under 100 words.

Important Learning:
A good prompt improves quality, accuracy and usefulness of claude's output.

Key Takeaway:
Always provide clear instructions, sufficient context and evaluate the final response before using it.
